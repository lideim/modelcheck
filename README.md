# modelcheck

**Проверка: настоящая ли нейросеть за вашим API-ключом.**

Перепродавцы продают «Claude Opus» и «GPT», а внутри бывает дешёвая модель с промптом «ты Claude», урезанные возможности или скрытый системный промпт на тысячи токенов, за который платите вы. `modelcheck` проверяет это за минуту и объясняет результат по-русски.

```bash
pip install modelcheck-ru
export MODELCHECK_KEY=sk-...
modelcheck run https://api.provider.com/v1 -m anthropic/claude-opus-4.8
```

## Что вы получите

Два вердикта, потому что это разные вопросы:

- **Модель** — настоящая ли: ✅ похоже на настоящую · ⚠️ подозрительно · ❌ признаки подмены · ❔ нет данных
- **Обслуживание** — честно ли работает посредник: ✅ без вмешательства · ⚠️ вмешивается (скрытый промпт, игнор параметров, урезания)

Модель может быть настоящей, а посредник при этом дописывает свои 4000 токенов к каждому запросу. `modelcheck` показывает и то и другое.

## Кого проверяет

Claude · GPT и o-серия · Gemini и Gemma · Grok · DeepSeek · Qwen · GLM · Kimi · Doubao · MiniMax · Llama · Mistral · Phi · Nemotron · Cohere · Amazon Nova · YandexGPT · GigaChat

Работает с любым провайдером, у которого OpenAI-совместимый API (`/v1/chat/completions`) или API Anthropic (`/v1/messages`).

## Проверки

| Проверка | Уровень | Что ловит |
|---|---|---|
| Подпись размышлений Claude | quick | криптоподпись Anthropic: подделать нельзя |
| Скрытый системный промпт | quick | лишние входные токены на сообщение из одного символа |
| Поле model, фантомная модель | quick | Haiku вместо Opus, ответ на несуществующую модель |
| Форма ответа | quick | `reasoning_content` и `<think>` у «Claude/GPT», чужой `usage` |
| Личность и ловушки | quick | «я DeepSeek», служебные токены других семейств, иероглифы, игнор вашего системного промпта |
| Размышления reasoning-моделей | standard | зашифрованные размышления OpenAI/xAI, chat-версия вместо reasoner |
| Подмена на поздних ходах | standard | настоящая модель в начале диалога, дешёвая — дальше |
| Отпечаток токенизатора | standard | текст режется как у другой модели (нужен эталон) |
| Инструменты | standard | вырезанный tool use |
| Длинный контекст | full | обрезанный контекст |
| «Случайное число» | full | подмена уровня внутри семейства (нужен эталон) |
| «Сорок вопросов» | full | точная модель по однословным ответам (нужен эталон) |

Список в терминале: `modelcheck list`. Что у какого производителя можно проверить: `modelcheck makers`.

Формулировки проверок каждый раз случайные и спрятаны в обычные рабочие вопросы, чтобы посредник не мог узнать проверку и подставить на неё настоящую модель. Повторить прогон один в один: `--seed`.

## Команды

```bash
# проверить
modelcheck run URL -m МОДЕЛЬ [-l quick|standard|full] [-n 3] [--md отчёт.md] [--json отчёт.json]

# следить по расписанию: подмену иногда включают только в часы пик
modelcheck watch URL -m МОДЕЛЬ --every 60 --log история.jsonl

# снять эталон с официального ключа производителя — включает сильные проверки
modelcheck baseline https://api.anthropic.com -m claude-opus-4-8 -p anthropic -k sk-ant-... --full
modelcheck baselines            # какие эталоны есть и не устарели ли
```

| Параметр | Что делает |
|---|---|
| `-m, --model` | модель так, как её называет провайдер |
| `-p, --protocol` | `openai` (по умолчанию) или `anthropic` — для `/v1/messages` |
| `-l, --level` | `quick` ~20 запросов · `standard` ~45 · `full` ~120 и длинный текст |
| `-n, --times` | несколько прогонов подряд: у пула аккаунтов каждый запрос может уйти на другой бэкенд |
| `--seed` | повторить прогон с теми же формулировками |
| `--only` | только указанные проверки: `--only hidden_prompt,identity` |
| `--md / --json` | сохранить отчёт, например чтобы приложить к обращению в поддержку |
| `-q, --quiet` | только итог |

**Код выхода:** `0` — настоящая, `1` — подозрительно, `2` — подмена, `3` — нет данных. Удобно в CI и скриптах.

## Как сравнить провайдеров

Проверьте одну и ту же модель у разных продавцов:

```bash
for url in https://api.one.com/v1 https://api.two.ru/v1; do
  MODELCHECK_KEY=... modelcheck run $url -m anthropic/claude-sonnet-4.6 -q
done
```

Сильнее всего проверки работают с эталонами. Снимите их один раз с официального ключа (`modelcheck baseline … --full`), и токенизатор, «случайное число» и «сорок вопросов» начнут сравнивать провайдера с настоящей моделью. Эталоны хранятся в `~/.modelcheck/baselines/` (папку можно сменить переменной `MODELCHECK_HOME`) и считаются устаревшими через 90 дней.

## Безопасность ключа

- Ключ отправляется только на проверяемый адрес и больше никуда.
- В отчётах ключ маскируется: `sk-u…0cec`.
- Передавайте ключ через `MODELCHECK_KEY`, а не через `-k`, чтобы он не попал в историю терминала.

## Ограничения

- **Один прогон — не приговор.** Подмена бывает только в часы пик или после первых ходов. Для уверенности используйте `-n 3` и `watch`.
- **Криптоподпись есть только у Claude.** У OpenAI, xAI и Gemini проверяются зашифрованные размышления, но многие посредники не поддерживают нужный API. Для остальных проверка идёт по протоколу, токенизатору и поведению.
- **Без эталонов** три сильные проверки только собирают данные и не выносят вердикт.
- Родные протоколы YandexGPT и GigaChat пока не поддерживаются, только OpenAI-совместимые шлюзы к ним.

## Разработка

```bash
git clone https://github.com/lideim/modelcheck && cd modelcheck
pip install -e ".[dev]" && pytest
```

Новая проверка — папка в `src/modelcheck/checks/` с классом `Check` и декоратором `@register`. Новый производитель — папка в `src/modelcheck/makers/` с объектом `PROFILE`.
