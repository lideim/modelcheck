# modelcheck

**Проверка: настоящая ли нейросеть за вашим API-ключом.**

Перепродавцы продают «Claude» и «GPT», а внутри бывает дешёвая модель, урезанные возможности или скрытый промпт на тысячи токенов, за который платите вы. `modelcheck` проверяет это за минуту и объясняет результат по-русски.

```bash
pip install modelcheck
export MODELCHECK_KEY=sk-...
modelcheck run https://api.provider.com/v1 -m anthropic/claude-opus-4.8
```

## Результат

Два вердикта, потому что это разные вопросы:

- **Модель:** ✅ настоящая · ⚠️ подозрительно · ❌ подмена · ❔ нет данных
- **Обслуживание:** ✅ без вмешательства · ⚠️ посредник вмешивается (скрытый промпт, игнор параметров, урезания)

## Кого проверяет

Claude · GPT · Gemini · Grok · DeepSeek · Qwen · GLM · Kimi · Doubao · MiniMax · Llama · Mistral · Phi · Nemotron · Cohere · Nova · YandexGPT · GigaChat

Подходит любой провайдер с OpenAI-совместимым API или API Anthropic (`-p anthropic`).

## Что проверяет

| Проверка | Что ловит |
|---|---|
| Подпись размышлений | криптоподпись Claude: подделать нельзя |
| Скрытый промпт | лишние входные токены на сообщение из одного символа |
| Поле model | Haiku вместо Opus, ответ на несуществующую модель |
| Форма ответа | чужие поля: `reasoning_content`, `<think>`, чужой `usage` |
| Личность и ловушки | «я DeepSeek», служебные токены других моделей, игнор вашего промпта |
| Размышления | chat-версия вместо reasoning-модели |
| Поздние ходы | настоящая модель в начале диалога, дешёвая — дальше |
| Токенизатор, отпечатки | текст режется и отвечает как другая модель (нужен эталон) |

Формулировки каждый раз случайные, чтобы посредник не узнал проверку.

## Команды

```bash
modelcheck run URL -m МОДЕЛЬ [-l quick|standard|full] [-n 3] [--md отчёт.md]
modelcheck watch URL -m МОДЕЛЬ --every 60           # проверять по расписанию
modelcheck baseline URL -m МОДЕЛЬ -k ОФИЦИАЛЬНЫЙ_КЛЮЧ --full   # эталон для сильных проверок
modelcheck list | makers | baselines
```

Код выхода: `0` настоящая, `1` подозрительно, `2` подмена, `3` нет данных.

## Важно

- Ключ уходит только на проверяемый адрес и маскируется в отчётах.
- Один прогон — не приговор: для уверенности используйте `-n 3` и `watch`.
